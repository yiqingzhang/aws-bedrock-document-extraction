QUICK START (3 Steps):
─────────────────────────────────────────────────────────────────────

1. Install Dependencies
   cd bedrock
   pip install -r requirements.txt

2. Configure AWS Credentials
   aws configure
   (Enter your AWS Access Key, Secret Key, and region: ap-southeast-2)

3. Run Extraction Pipeline
   python run_extraction.py

That's it! The system will process all 501 invoices and generate metrics.

TROUBLESHOOTING:
─────────────────────────────────────────────────────────────────────

Issue: AWS credentials error
Fix:   Run 'aws configure' and enter your credentials

Issue: Bedrock access denied
Fix:   Ensure IAM user has 'bedrock:InvokeModel' permission

Issue: Script interrupted
Fix:   Just run it again! Already-processed files are skipped
