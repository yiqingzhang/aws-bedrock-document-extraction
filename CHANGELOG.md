# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-11-02

### Added
- Initial public release
- Complete Sparrow Invoice Dataset (501 annotated invoices)
- AWS Bedrock Claude Vision integration for invoice extraction
- Support for Claude Sonnet 3.5 and 4.5 models
- Comprehensive evaluation framework with field-level accuracy metrics
- Interactive web-based extraction results viewer
- Dataset utilities for exploration and processing
- Extensive documentation and examples
- GitHub Actions CI/CD workflow
- MIT License
- Contributing guidelines

### Project Structure
- Organized codebase with `src/`, `docs/`, `examples/`, and `tests/` directories
- Separate modules for Bedrock extraction and dataset utilities
- Professional README with badges and clear documentation
- Example scripts demonstrating basic usage

### Documentation
- Quick Start Guide
- Configuration Guide
- Implementation Summary
- Evaluation Improvements guide
- API documentation in code docstrings

### Features
- Automatic retry logic with exponential backoff
- Checkpoint/resume capability for interrupted extractions
- Multi-model comparison support
- Comprehensive error handling and logging
- Field-level accuracy evaluation
- Interactive visualization tools
